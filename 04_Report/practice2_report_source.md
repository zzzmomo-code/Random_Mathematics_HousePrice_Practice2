**摘要**：本文针对 300 条房屋销售价格样本，在剔除无物理意义的索引列 `Id` 后，基于 8 项物理特征开展由简到难的回归建模与特征贡献度分析。在固定划分（240 训练 / 60 测试）与无泄露 5 折交叉验证框架下，依次比较了单变量直线与抛物线拟合、多元线性回归（正规方程、手动批量梯度下降与 MATLAB `fitlm` 三种等价求解）、多元二次多项式、岭回归与 Lasso 正则化以及决策树、随机森林和梯度提升树（GBDT）共 4 阶层 10 类模型。结果表明，多元线性回归在测试集上取得最优预测精度（$\text{RMSE} = \$11,030$，$R^2 = 0.9770$，$\text{MAPE} = 4.27\%$），高于多元二次项与树集成模型；进一步通过标准化系数、留一特征法、Lasso 正则化路径及随机森林袋外置换重要性四种互补方法交叉检验，排序完全一致（方法间 Spearman 秩相关均为 $1.000$），明确识别出对房价贡献最大的前三项核心特征依次为地上居住面积 `GrLivArea`、综合质量 `OverallQual` 与车库容量 `GarageCars`。

# 1. 问题背景与数据概况

房屋销售价格受居住面积、装修质量、配套设施与建造年代等多维因素共同影响。本次实践所用数据集采集自聚合数据平台，共包含 $N = 300$ 条观测样本、10 个字段，无任何缺失值。其中首列 `Id` 为 $1 \sim 300$ 的顺序样本编号，不承载房屋物理属性，建模前予以显式剔除；最终保留 8 项房屋物理特征作为自变量 $\mathbf{X} \in \mathbb{R}^{300 \times 8}$，以房屋销售价格 `SalePrice`（单位：美元）作为因变量 $\mathbf{y}$。

# 2. 由简到难的回归建模拟合

为客观比较不同复杂度模型的泛化能力，所有实验在 MATLAB R2025b 中固定随机种子 `rng(42)` 执行：先按 80%/20% 划分为训练集（$N_{\text{train}} = 240$）与独立测试集（$N_{\text{test}} = 60$），再在训练集内进行 5 折交叉验证（5-Fold CV）。凡涉及特征标准化，均值与标准差均严格在每折训练子集内部估计，避免数据泄露。各模型统一采用均方根误差 $\text{RMSE}$ 与可决系数 $R^2$ 评价：

$$\text{RMSE} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}$$

$$R^2 = 1 - \frac{\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{n}(y_i - \bar{y})^2}$$

## 2.1 单变量曲线拟合：一次直线与二次抛物线

从最简单模型出发，选取与房价相关性最强的单特征 `GrLivArea` 分别拟合一次直线（`poly1`）与二次抛物线（`poly2`）：

$$\hat{y}_{\text{poly1}} = \beta_0 + \beta_1 x, \qquad \hat{y}_{\text{poly2}} = \beta_0 + \beta_1 x + \beta_2 x^2$$

训练集拟合得一次方程 $\hat{y} = 54.46\,x + 125,963.25$，5 折 CV RMSE 为 $\$49,877$（CV $R^2 = 0.5370$），测试集 RMSE 为 $\$52,260$（$R^2 = 0.4841$）。引入二次项后，拟合曲线与一次直线几乎重合（图 2a），CV RMSE 微升至 $\$49,929$，且二次项显著性检验 $p = 0.3223 > 0.05$。图 2b 残差图无明显弯曲趋势，但上下离散幅度高达 $\pm \$100\text{k}$，说明单变量误差的核心来源是遗漏其余房屋属性，而非面积与房价之间存在高阶曲率。

## 2.2 多元线性回归、多元多项式与正则化模型

将全部 8 项物理特征纳入多元线性回归模型 $\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}$，分别通过正规方程解析求解、标准化特征批量梯度下降（学习率 $\alpha = 0.05$，迭代 2500 步）与 MATLAB 内置 `fitlm` 三种路径求解普通最小二乘（OLS）估计：

$$\hat{\boldsymbol{\beta}}_{\text{OLS}} = (\mathbf{X}^\top \mathbf{X})^{-1}\mathbf{X}^\top \mathbf{y}$$

$$\boldsymbol{\beta}^{(t+1)} = \boldsymbol{\beta}^{(t)} - \frac{\alpha}{n}\mathbf{Z}^\top(\mathbf{Z}\boldsymbol{\beta}^{(t)} - \mathbf{y})$$

数值核验表明，梯度下降经约 120 步即逼近解析解（图 4a），终态梯度范数降至 $2.82 \times 10^{-10}$；三种求解器在测试集预测上的最大绝对差仅 $2.44 \times 10^{-8}$（梯度下降与 `fitlm` 系数最大差为 $1.63 \times 10^{-9}$，正规方程与 `fitlm` 为 $1.30 \times 10^{-6}$），证实三者数值等价。引入全部 8 特征后，模型整体显著性 $F = 1280.57$（$p = 1.17 \times 10^{-186}$），5 折 CV RMSE 由单变量的 $\$49,877$ 骤降至 $\$11,712$，测试集 RMSE 降至 $\$11,030$（$R^2 = 0.9770$，平均绝对百分比误差 $\text{MAPE} = 4.27\%$）。

在此基础上构造多元纯二次模型（线性项与 8 个平方项，共 16 项）及含交互全二次模型（共 44 项）。如表 2 所示，全二次模型虽将训练集 RMSE 压低至 $\$10,185$（$R^2 = 0.9817$），但 5 折 CV RMSE 反升至 $\$12,325$，测试集 RMSE 恶化至 $\$12,194$（测试集调整后 $R^2$ 降至 $0.8895$），在 $N_{\text{train}} = 240$ 的小样本下出现了典型的方差膨胀与过拟合。

进一步引入 $L_2$ 岭回归（Ridge）与 $L_1$ 稀疏回归（Lasso）以检验惩罚收缩效果：

$$\hat{\boldsymbol{\beta}}_{\text{Ridge}} = \arg\min_{\boldsymbol{\beta}}\left\{\frac{1}{2n}\|\mathbf{y} - \mathbf{Z}\boldsymbol{\beta}\|_2^2 + \lambda\|\boldsymbol{\beta}\|_2^2\right\}$$

$$\hat{\boldsymbol{\beta}}_{\text{Lasso}} = \arg\min_{\boldsymbol{\beta}}\left\{\frac{1}{2n}\|\mathbf{y} - \mathbf{Z}\boldsymbol{\beta}\|_2^2 + \lambda\|\boldsymbol{\beta}\|_1\right\}$$

由于特征间几乎无共线性且 $n \gg p$（$240 \gg 8$），岭回归 5 折交叉验证选出 $\lambda = 0$，自动退化为无偏 OLS；Lasso 在最小误差点 $\lambda_{\min} = 1$ 处保留全部 8 特征，测试集 RMSE 为 $\$11,030$（$R^2 = 0.9770$）；在更简洁的一倍标准误点 $\lambda_{\text{1SE}} = 775.7$ 处，`LotArea` 标准化系数被剧烈压缩至 $-\$114$，而测试集 $R^2$ 仍保持 $0.9765$（RMSE $\$11,156$）。

# 3. 特征贡献度多维评价与 Top 3 识别

在多元回归中，不能直接以原始回归系数 $\hat{\beta}_j$ 的绝对值大小判断特征重要性，因为各特征物理量纲悬殊：例如表 3 中 `GarageCars` 原始系数为 $+\$19,103$/车位，远大于 `GrLivArea` 的 $+\$54.79$/平方英尺，但前者标准差仅 $1.11$ 车位，后者标准差高达 $1042.6$ 平方英尺。为此，本实验设计了四种相互独立且互补的特征贡献度评价方法进行交叉验证：

1. **方法 A（标准化 OLS 回归系数 $|\beta_j^*|$）**：对特征执行 Z-score 标准化后重新回归，计算单个特征变化 1 个样本标准差所引起的房价美元变动：

$$\beta_j^* = \hat{\beta}_j \cdot s_{x_j}, \qquad z_{ij} = \frac{x_{ij} - \bar{x}_j}{s_{x_j}}$$

2. **方法 B（留一特征边际贡献 $\Delta\text{RMSE}_{\text{CV}}$ 与单变量 $R^2$）**：逐一从全模型剔除第 $j$ 个特征并重算 5 折 CV RMSE，以误差增幅衡量不可替代性：

$$\Delta\text{RMSE}_{\text{CV}}^{(j)} = \text{RMSE}_{\text{CV}}^{(-j)} - \text{RMSE}_{\text{CV}}^{\text{full}}$$

3. **方法 C（Lasso 正则化路径入模顺序）**：沿惩罚系数 $\lambda$ 由大到小递减，观察各特征首次获得非零系数的临界 $\lambda$（图 4b），越早入模说明解释信号越强。

4. **方法 D（随机森林 OOB 袋外置换重要性）**：随机打乱袋外样本中特征 $j$ 的取值，以非线性模型预测误差的标准化增幅进行独立核验。

综合表 3、图 4b 与图 5 可得两项核心发现：第一，**四种评价方法高度一致锁定 Top 3 核心特征**。无论基于线性参数（方法 A）、交叉验证边际误差（方法 B）、稀疏惩罚路径（方法 C）还是非参数树集成（方法 D），全部 8 项特征的排序完全一致（方法间 Spearman 秩相关系数均为 $1.000$）。对房价贡献最大的前三项特征依次为：**第 1 名 `GrLivArea`（地上居住面积）**、**第 2 名 `OverallQual`（综合质量）**、**第 3 名 `GarageCars`（车库容量）**。三者标准化系数贡献占比合计达 $68.2\%$，其中仅剔除 `GrLivArea` 就会使 5 折 CV RMSE 暴增 $+\$48,882$（$\Delta R^2_{\text{CV}} = 0.6632$），剔除 `OverallQual` 与 `GarageCars` 分别使误差增加 $+\$26,231$ 与 $+\$13,357$。

第二，**多变量建模揭示了单变量统计容易遗漏的遮蔽效应与冗余特征**。在单变量相关中，`OverallQual`（$R^2 = 0.1245$）与 `GarageCars`（$R^2 = 0.1234$）几乎并列，原因在于样本中 `OverallQual` 与 `GrLivArea` 存在轻微负相关（$r = -0.1164$）；在多元 OLS 中控制居住面积后，`OverallQual` 的净贡献（$|\beta^*| = \$34,087$）明显领先于 `GarageCars`（$\$21,319$）。同理，`BedroomAbvGr` 单变量几乎不相关（$R^2 = 0.0002$），控制面积后呈现显著正向贡献（$p = 1.18 \times 10^{-16}$，每增 1 间卧室增价 $\$4,674$）；而 `LotArea` 回归系数不显著（$p = 0.231$），剔除后 5 折 CV RMSE 反而微降 $\$49$，属冗余特征。从物理意义看，Top 3 分别代表“空间体量（约 $\$54.8/\text{ft}^2$）、建筑品质（约 $\$11,892$/级）、刚性配套（约 $\$19,103$/车位）”三大核心定价维度，高度契合住宅市场规律。

# 4. 结论与思考

1. **模型复杂度须与样本规模及数据机理匹配**：在 $N=300$ 的小样本条件下，多元线性回归（测试集 $R^2 = 0.9770$，RMSE $= \$11,030$）显著优于易过拟合的 44 项全二次多项式（RMSE $= \$12,194$）以及依赖阶梯近似的决策树、随机森林与 GBDT，体现了偏差-方差权衡在统计建模中的关键作用。
2. **理论推导与数值优化相互印证**：多元 OLS 的正规方程解析解、手动批量梯度下降迭代解与 MATLAB `fitlm` 求解结果在 $10^{-8}$ 精度内一致；在近似正交（$\max\text{VIF} = 1.0396$）的数据上岭回归与 Lasso 虽未进一步降低测试误差，但 Lasso 路径直观刻画了特征重要性的先后层次。
3. **科学评估特征贡献须消除量纲与共变干扰**：直接比较原始系数会严重低估大尺度特征 `GrLivArea` 的主导地位；经四维方法交叉验证，可靠确立了 `GrLivArea`、`OverallQual`、`GarageCars` 为 Top 3 核心特征，并识别出 `LotArea` 在本样本中的统计不显著性。
4. **实验边界与展望**：本结论基于当前 300 条结构化样本与 8 项房屋物理属性得出，残差呈轻尾有界特征，尚未包含区位地段与宏观利率等因素；若推广至更大规模的真实跨区域房产数据，可进一步检验对数目标变换与非线性交互特征的改进空间。
